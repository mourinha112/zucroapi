---
title: 'Dados da Conta'

description: 'Retorna os dados do seller/empresa vinculado à API Key'
---

## Descrição

Retorna as informações cadastrais do seller (vendedor) ou empresa associada à API Key utilizada na requisição. Útil para validar a integração e confirmar os dados da conta.

## Response

<ResponseField name="object" type="string">
  Sempre `account`
</ResponseField>

<ResponseField name="id" type="string">
  ID único da conta
</ResponseField>

<ResponseField name="name" type="string">
  Nome do seller ou razão social da empresa
</ResponseField>

<ResponseField name="email" type="string">
  Email da conta
</ResponseField>

<ResponseField name="document" type="string">
  CPF (pessoa física) ou CNPJ (pessoa jurídica)
</ResponseField>

<ResponseField name="person_type" type="string">
  Tipo de pessoa: `PF` (Pessoa Física) ou `PJ` (Pessoa Jurídica)
</ResponseField>

<ResponseField name="phone" type="string">
  Telefone de contato
</ResponseField>

<ResponseField name="account_status" type="string">
  Status da conta: `active`, `pending`, `blocked`, `suspended`
</ResponseField>

<ResponseField name="identity_verified" type="boolean">
  Se a identidade do seller foi verificada
</ResponseField>

<ResponseField name="payment_provider" type="string">
  Provedor de pagamento configurado
</ResponseField>

<ResponseField name="created_at" type="string">
  Data de criação da conta (ISO 8601)
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET https://api.appzucropay.com/api/v1/account \
  -H "X-API-Key: zp_sua_api_key_aqui"
```

```javascript JavaScript
const response = await fetch('https://api.appzucropay.com/api/v1/account', {
  headers: {
    'X-API-Key': 'zp_sua_api_key_aqui'
  }
});

const data = await response.json();
console.log(data.name);     // "Empresa XYZ Ltda"
console.log(data.document); // "12345678000199"
console.log(data.email);    // "contato@empresa.com"
```

</RequestExample>
