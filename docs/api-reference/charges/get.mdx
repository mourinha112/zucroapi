---
title: 'Consultar Cobrança'
api: 'GET https://api.appzucropay.com/api/v1/charges/{id}'
description: 'Consulta os detalhes de uma cobrança específica'
---

## Path Parameters

<ParamField path="id" type="string" required>
  ID da cobrança
</ParamField>

## Response

<ResponseField name="id" type="string">
  ID único da cobrança
</ResponseField>

<ResponseField name="object" type="string">
  Sempre `charge`
</ResponseField>

<ResponseField name="billing_type" type="string">
  Tipo da cobrança: `PIX`, `CREDIT_CARD`, `BOLETO`
</ResponseField>

<ResponseField name="status" type="string">
  Status: `PENDING`, `RECEIVED`, `OVERDUE`, `REFUNDED`, `CANCELLED`
</ResponseField>

<ResponseField name="value" type="number">
  Valor bruto da cobrança
</ResponseField>

<ResponseField name="net_value" type="number">
  Valor líquido (após taxas)
</ResponseField>

<ResponseField name="description" type="string">
  Descrição da cobrança
</ResponseField>

<ResponseField name="pix" type="object">
  Dados do PIX (se aplicável)
</ResponseField>

<ResponseField name="payment_date" type="string">
  Data do pagamento (se pago)
</ResponseField>

<ResponseField name="created_at" type="string">
  Data de criação
</ResponseField>

<ResponseField name="metadata" type="object">
  Metadados adicionais
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET https://api.appzucropay.com/api/v1/charges/abc123-def456 \
  -H "X-API-Key: zp_sua_api_key_aqui"
```

```javascript JavaScript
const response = await fetch('https://api.appzucropay.com/api/v1/charges/abc123-def456', {
  headers: {
    'X-API-Key': 'zp_sua_api_key_aqui'
  }
});

const data = await response.json();
```

</RequestExample>
