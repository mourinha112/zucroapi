## Visão Geral

A ZucroPay cobra uma taxa por transação que varia conforme o método de pagamento. Não há mensalidade ou taxa de setup.

## Como Funciona

### Exemplo PIX - R$ 100,00

| Item | Valor |
|------|-------|
| Valor da venda | R$ 100,00 |
| Taxa percentual (5,99%) | - R$ 5,99 |
| Taxa fixa | - R$ 2,50 |
| Reserva (5%) | - R$ 4,58 |
| **Você recebe** | **R$ 86,93** |

<Note>
  A reserva de 5% é liberada após 30 dias automaticamente.
</Note>

### Exemplo Cartão - R$ 100,00 em 3x

| Item | Valor |
|------|-------|
| Valor da venda | R$ 100,00 |
| Taxa percentual (5,99%) | - R$ 5,99 |
| Taxa fixa | - R$ 2,50 |
| Taxa de parcelamento (3 × 2,49%) | - R$ 7,47 |
| Reserva (5%) | - R$ 4,20 |
| **Você recebe** | **R$ 79,84** |

## Quem Paga a Taxa?

Você pode escolher quem paga a taxa ao criar o produto:

### Vendedor paga (Padrão)

A taxa é descontada do valor que você recebe. O cliente paga exatamente o valor do produto.

```javascript
// Produto de R$ 100
// Cliente paga: R$ 100
// Você recebe: ~R$ 91 (após taxas)
```

### Comprador paga

A taxa é adicionada ao valor final. O cliente paga mais, mas você recebe o valor integral.

```javascript
// Produto de R$ 100 com taxa do comprador
// Cliente paga: ~R$ 109 (valor + taxas)
// Você recebe: ~R$ 100
```

<Info>
  Configure isso ao criar cada produto no Dashboard ou via API.
</Info>

## Reserva de Segurança

5% de cada venda fica reservado por 30 dias como garantia contra:

- Chargebacks
- Estornos
- Disputas

Após 30 dias, o valor é **automaticamente liberado** para seu saldo disponível.

### Acompanhando Reservas

No Dashboard, vá em **Finanças** para ver:

- Saldo disponível
- Saldo em reserva
- Próximas liberações

## Taxas Customizadas

Parceiros com alto volume podem negociar taxas especiais. Entre em contato:

- **Email:** parcerias@appzucropay.com
- **Volume mínimo:** R$ 50.000/mês
